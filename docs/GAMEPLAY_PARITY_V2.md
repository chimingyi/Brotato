# v2 玩法系统对标规格

目标是完整复现“短波次自动战斗 + 波间构筑商店”这一类玩法的系统深度，同时保留《薯星幸存者》的原创世界观、角色、美术、名称、描述和数值。

## 边界

可以对标：玩法规则、系统结构、交互节奏、构筑深度、难度层级。

不会复制：其他游戏的角色造型、名称、图标、音频、文本、代码、关卡素材和精确数值表。

## 一局游戏的完整流程

1. 选择探险员。
2. 从该探险员允许的武器中选择一把初始武器。
3. 进入第 1 波，在限定时间内移动、自动攻击和收集材料。
4. 波次结束时自动收取场上剩余材料，并结算收获收益。
5. 如果积累了等级，逐次完成升级四选一。
6. 进入商店，购买武器和道具；可以刷新、锁定、出售和合成。
7. 点击下一波，带着永久属性和装备继续战斗。
8. 第 20 波击败最终首领或坚持到计时结束后通关。
9. 根据角色、难度和表现解锁新内容，并保存到本地。

## 里程碑

### M1：完整一波循环

角色/武器选择 → 第 1 波 → 材料结算 → 升级 → 商店 → 下一波。先使用少量内容证明状态机可靠。

状态：已完成并通过浏览器实玩测试。M1 只证明核心循环可靠，不代表全部内容已经完成。

### M2：商店和装备构筑

六槽、四货架、刷新、锁定、出售、四品质合成、类别加成。

状态：已完成并通过连续合成、类别加成和六槽满载浏览器测试。

### M3：完整属性与内容框架

把属性、武器、道具和敌人改成数据驱动，补足主要机制与内容数量。

状态：已完成 12 名角色、24 把武器、80 件道具和主要攻击派生机制，并通过数据与浏览器运行测试。

### M4：20 波、精英、首领与难度

完成整局难度曲线、危险等级和最终通关条件。

状态：已完成 20 波生成表、16 种普通敌人、4 种精英、3 种首领与 D0-D4，并通过特殊波和最终波浏览器测试。

### M5：解锁、存档、无障碍与发布

完成局外成长、图鉴、设置、全流程测试和 v2.0 发布。

状态：全部系统已实现，发布前平衡审计、本地回归和线上 v2.0 验收均已通过。

### M6：角色特性、道具触发与敌人变异

让构筑差异不只来自属性数字：12 名角色各有一项实际改变战斗规则的特性，8 件核心道具拥有条件触发，敌人会在高危险等级获得硬化、迅捷、巨化、狂怒、晶盾或不稳定变异。危险等级扩展为 D0-D6，D5-D6 可出现双重变异。

状态：功能实现、专项浏览器测试、D6 最终波、完整 20 波回归和 v2.1 线上发布验收均已通过。

### M7：构筑进化、事件与诅咒风险

让一局游戏在中后期继续产生新决策：角色拥有开局出身；指定传说武器可以付费进化并改变攻击规则；第 5、10、15 波后出现二选一事件；诅咒道具提供强力属性，同时增强敌人并提高掉落；4 种精英拥有不同的周期性技能。

状态：数据、战斗逻辑、界面和测试快照均已实现，专项测试、完整回归、存档迁移和 v2.2 线上发布验收全部通过。
