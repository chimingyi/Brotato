# 第一版项目总结

## 项目结果

“薯星幸存者”第一版已经具备完整的开始、战斗、成长和结算流程。项目不依赖第三方游戏框架，使用浏览器原生能力实现，适合继续学习和修改。

## 已完成功能

- 键盘与手机虚拟摇杆移动。
- 自动寻找最近敌人并攻击。
- 3 种属性和外观不同的敌人。
- 种子、多重射击、守护叶片和星芒爆发等武器效果。
- 经验掉落、等级提升与随机三选一。
- 8 类升级方向。
- 动态难度、生命、受伤、失败和 5 分钟胜利。
- 程序生成音效、音效开关、粒子和受伤闪烁。
- 本地最高生存纪录。
- 响应式桌面与手机界面。

## 当前限制

- 程序图形是占位美术，后续可以替换为原创图片或动画。
- 数值只经过自动化试玩，需要开发者亲自体验后继续平衡。
- 最高纪录只保存在当前浏览器，没有在线排行榜。
- 在线排行榜尚未实现；当前最高纪录只保存在玩家自己的浏览器中。

## 发布地址

- 源代码：<https://github.com/chimingyi/Brotato>
- 在线游戏：<https://chimingyi.github.io/Brotato/>
- 线上页面已经过实际加载和 8 秒自动战斗测试，浏览器错误和警告为 0。

## “完成”的定义

这里的“第一版完成”不是永远停止开发，而是已经达到可发布、可游玩、可收集反馈的状态。后续新增角色、武器和美术属于下一版本迭代。
