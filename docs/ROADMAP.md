# 开发路线图

这份路线图会随着开发调整。每个阶段都要达到“能运行、能测试、能说明白”三个标准。

## 阶段 0：项目准备

- [x] 初始化仓库
- [x] 确定使用 HTML Canvas + JavaScript
- [x] 建立 README、路线图和开发日志
- [ ] 关联 GitHub 远程仓库

## 阶段 1：角色与场地

- [x] 创建游戏画布
- [x] 键盘控制角色移动
- [x] 限制角色不能跑出场地
- [x] 添加手机触摸控制

## 阶段 2：战斗核心

- [x] 生成追踪玩家的敌人
- [x] 自动瞄准和自动攻击
- [x] 敌人受伤、死亡和掉落能量
- [x] 玩家生命值、受伤和游戏结束

## 阶段 3：成长系统

- [x] 收集经验并升级
- [x] 升级时三选一
- [x] 至少 6 种升级效果
- [x] 一局完整的难度曲线

## 阶段 4：内容与体验

- [x] 至少 3 种敌人
- [x] 至少 3 种武器
- [x] 音效、粒子效果和屏幕反馈
- [x] 开始、暂停、结算和重新开始界面
- [x] 本地最高分

## 阶段 5：测试与发布

- [x] 键盘与手机测试
- [x] 修复主要问题
- [ ] 补充玩法说明和截图
- [ ] 发布到 GitHub Pages
- [x] 写项目总结

## 第一版完成标准

玩家能完成一局 5 分钟的游戏；过程中会移动、自动战斗、拾取经验、选择升级；失败后可以重新开始；电脑和手机浏览器都能正常游玩。
